        *Last updated: 20 September 2026*

        This policy covers **Bili Reupload**, a personal command-line tool that
        uploads videos to its operator's own YouTube channel. It is not a
        hosted service and has no users other than its operator.

        ### Information collected

        None. The tool has no servers, no database, no analytics and no
        telemetry. It does not collect, transmit or sell personal information
        about anyone.

        ### Google user data

        The tool requests one OAuth scope,
        `https://www.googleapis.com/auth/youtube.upload`. It uses this scope
        for exactly one purpose: uploading video files to the YouTube channel
        of the Google account that granted access.

        The resulting OAuth credential is written to a file on the operator's
        own computer and is never transmitted anywhere except to Google's own
        API endpoints. No Google user data is shared with any third party, used
        for advertising, or used to train any model.

        Bili Reupload's use of information received from Google APIs adheres to
        the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
        including the Limited Use requirements.

        ### Retention and deletion

        The stored credential remains on the local machine until it is deleted.
        Access can be revoked at any time from
        [Google Account permissions](https://myaccount.google.com/permissions),
        which immediately invalidates it.
